# Design System — «Graphite & Cobalt» (v2)

> v2 (2026-10): бренд-колір змінено з зеленого на кобальт за правилом 60/30/10; деталі й нова палітра — у [brand.md](brand.md). Таблиця токенів нижче — історія v1.

Візуальна ідея: **інвестиційний research-продукт + фінтех-дашборд, а не рієлторський сайт.**
Тепле «паперове» тло, глибокий зелено-чорний ink, один акцент, семантичні кольори тільки для ризику/вердикту.
Жодних золотих градієнтів, стокових фото рукостискань і «ключів від квартири».

## Принципи

1. **Complex intelligence → simple decision.** Verdict — найбільший елемент екрана; докази — на один клік глибше.
2. **Невизначеність — візуальна сутність.** Діапазони, а не точки; confidence — смуга; відсутні дані — штрих-пунктирний стан, не «0».
3. **FACT / INFERENCE / ESTIMATE видно завжди** (бейдж: суцільний / пунктирний / подвійний контур).
4. **Щільність без шуму.** Сітка 4/8 px, багато повітря між групами, мало ліній-розділювачів, табличні цифри (`tabular-nums`).
5. **Рух пояснює.** Анімація — тільки там, де вона показує зв'язок або зміну стану (див. Motion).

## Типографіка

- **Display / headline:** *Source Serif 4* (є кирилиця) — спокійний, «редакційний» характер, довіра.
- **UI / body:** *Inter Tight* (кирилиця) — щільний, читабельний.
- **Числа / дані:** *JetBrains Mono* (кирилиця) з `font-variant-numeric: tabular-nums` — ціни й діапазони.
- Шкала: 12 / 14 / 16 / 18 / 22 / 28 / 40 / 64 (fluid `clamp` для hero).

## Компоненти (ядро)

`Verdict` (великий вердикт з причиною) · `RangeBar` (діапазон справедливої ціни + ask + пропозиція) ·
`ConfidenceMeter` (з розкладом на чинники) · `ProvenanceBadge` · `ScoreRing`/`SubscoreRow` (пояснюваний score) ·
`RiskCard` (розкривна, severity-смуга) · `LegalLight` (GREEN/YELLOW/RED) · `StepBrief` (по одному питанню) ·
`CompareMatrix` + `BestFit` · `PropertyMap` (MapLibre, шари) · `ScenarioTabs` (Cons/Base/Opt) · `Chip`, `Button`, `Field`.

## Motion

Бібліотека: `motion`. Принципи: spring з низьким bounce, 200–600 мс, `prefers-reduced-motion` вимикає все крім fade.

| Де | Що анімуємо | Навіщо |
|---|---|---|
| Hero | Послідовна поява рядків (mask-reveal), «дрейф» ліній-ізохрон на тлі, лічильники | Задати тон, показати «шари» даних |
| Hero → вхід | Два вхідні картки: hover зі зсувом стрілки | Підказка кліку |
| Brief | Slide + crossfade між кроками, progress-лінія, layout-анімація чіпів | Відчуття прогресу, орієнтація |
| Score reveal | Кільце заповнюється, числа count-up, subscores каскадом | Пояснити, з чого складається оцінка |
| RangeBar | Діапазон «розкривається» від центру, маркер ask «падає» на шкалу | Показати позицію ціни відносно fair range |
| Risk expansion | Accordion з `layout`-анімацією висоти | Не перенавантажувати, розкривати за запитом |
| Compare | Колонки перевпорядковуються за `layout` при зміні сортування; «Best fit» підсвічується | Показати зв'язок між даними й висновком |
| Scroll | Reveal-on-view (раз), sticky-прогрес звіту | Навігація довгим звітом |
| Inspection before/after | Слайдер `clip-path` | Показати знахідку |

Не робимо: parallax заради parallax, нескінченні loop-анімації, анімацію вердикту «для драматизму».

## Карти

Базова карта приглушена (positron), наші шари — єдине кольорове: об'єкт (brand), comps (info, розмір = схожість), POI (за категорією, монохром + 1 колір), ризикові зони (bad, напівпрозорі). Легенда завжди. Атрибуція OSM/OpenFreeMap обов'язкова.

## Адаптив і a11y

Mobile-first (≥ 360px). Звіт на мобільному — одна колонка зі sticky-вердиктом. Фокус-стани видимі, `aria-live` на оновлення результату, клавіатурна навігація для brief, `lang` на `<html>`, alt для фото, не покладатись на колір.

## Приклад мікрокопі (тон)

Спокійний, прямий, без маркетингових перебільшень. «Недостатньо даних, щоб назвати справедливу ціну» краще за «Ціну не розраховано».
