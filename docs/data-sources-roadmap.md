# Data sources beyond DIM.RIA — research & roadmap (2026-10)

Мета: кожен модуль звіту отримує дані з **офіційного / ліцензованого / відкритого** джерела з датою й статусом, а не з хардкоду.
Оцінка: **Цінність** для рішення покупця × **Доступність** (API, ліцензія, ціна) → пріоритет P0–P3.

> ⚠️ Правовий контекст. Закон № 4576-IX (набрав чинності 18.11.2025) дозволяє обмежувати доступ до відомостей публічних реєстрів у частині, що стосується нацбезпеки й оборони (оборонні підприємства, їхнє майно). Для звичайного житла доступ до витягів ДРРП зберігається, але частина сервісів (зокрема електронні витяги через Дію) у 2026 р. працювали з обмеженнями. Перед інтеграцією кожного реєстру перевіряти актуальний порядок і постанову КМУ № 1257 від 03.10.2025.

## 1. Юридична частина

| Джерело | Що дає для звіту | Доступ | Пріоритет | Нотатки |
|---|---|---|---|---|
| **ДРРП** (Мін'юст) — інформаційна довідка | власник, підстава, іпотека, арешти, обтяження, історія | офіційно: ЦНАП/нотаріус/онлайн-сервіс Мін'юсту; **платно** (~40 грн електронна, ~80 грн паперова, 2026) | **P0** (ручний оператор) | Пошук за об'єктом (адреса / кадастровий № / РНОНМ) або за суб'єктом. В MVP оператор замовляє довідку → PDF → AI-витяг полів → юрист підтверджує. |
| **Opendatabot API** | ДРРП, реєстр обтяжень та іпотек, суди, виконавчі провадження, компанії, моніторинг змін | комерційний API (ключ, тариф за запитами) | **P1** | Опубліковано список реєстрів, доступних через API (реєстр речових прав, обтяжень, іпотек). Дає **автоматизацію** юр-частини + **моніторинг** об'єкта до угоди (раптовий арешт/іпотека). Потрібен договір; перевірити покриття після Закону 4576. |
| **YouControl API** | забудовник/продавець-юрособа: фінстан, суди, санкції, пов'язані особи | комерційний API | P2 | Сильний для **developer DD** у новобудовах. Альтернатива/доповнення Opendatabot. |
| **ЄДР** (data.gov.ua) | статус юрособи-продавця/забудовника, керівники, бенефіціари | open data (CC-BY-подібна умова з посиланням) | P1 | Великий щомісячний дамп → власна індексація за ЄДРПОУ. |
| **Єдиний реєстр боржників** (data.gov.ua, оновлюється одразу після змін) | чи є продавець боржником (ризик арешту майна) | open data, комерційне використання з посиланням | **P1** | Перевірка продавця-фізособи за ПІБ+датою народження — лише за згоди / законної підстави; персональні дані → тільки у звіті замовника. |
| **ЄДРСР** (реєстр судових рішень) | спори щодо об'єкта/забудовника | open data + пошук | P2 | Через Opendatabot простіше. |
| **ЄДЕССБ** (e-construction.gov.ua) | дозволи, декларації, сертифікати введення, **ОНБ / МОНи** (об'єкти незавершеного будівництва, майбутня нерухомість) | **окремий API для сервісів нерухомості** (запущено 2023) — за договором | **P1** для новобудов | Ключ для перевірки «чи легальна новобудова, чи введена в експлуатацію». |
| **Державний земельний кадастр** | кадастровий №, цільове призначення, площа, форма власності | open dataset (щомісяця) + публічна карта | P1 | Для будинків/ділянок; для квартир — земля під багатоквартирним будинком. |
| **Prozorro.Sale** | **реальні ціни угод** на аукціонах (держмайно, банкрутство, оренда) + OCDS open data, публічне API | відкрите API | P2 | Єдине публічне джерело *фактичних* цін продажу (не оголошень) — для калібрування `askToSoldDiscount` по регіону. |

## 2. Ринок (ціни, пропозиція, оренда)

| Джерело | Що дає | Доступ | Пріоритет |
|---|---|---|---|
| **DIM.RIA API** ✅ (підключено) | оголошення продажу/оренди, середні ціни | ключ | P0 |
| **ЛУН** (lun.ua, ЛУН Статистика, Flatfy) | найкраща нормалізація новобудов, медіани, історія цін, перевірка забудовників | **публічного API немає**; доступ до даних — через партнерство (команда партнерств обслуговує банки, держпрограми, бізнеси). ToS забороняє масовий збір. | **P1 — переговори** |
| **OLX Нерухомість** | великий обсяг вторинки | Partner API лише для **власних** оголошень; чужі — ні | P3 |
| **Rieltor.ua, M2bomber, Address.ua** | агентські оголошення | без публічного API | P3 |
| **Власна база угод** (клієнтські кейси, зі згодою) | asking → sold, торг, час продажу | наша | **P0 (moat)** |
| **НБУ**: курс ✅, іпотечні ставки, індекси | конвертація, вартість кредиту, discount rate для інвест-моделі | open API | P1 (ставки) |
| **Держстат** (SDMX API) | ІСЦ, індекси вартості будівництва | open data | P2 — індексація кошторисів ремонту |
| Курорти: **AirDNA / Booking / Airbnb** | ADR, завантаженість для Буковеля, Трускавця, Яремче | платні/закриті | P2 — без них модель курорту позначена як неповна |

## 3. Локація, безпека, комфорт

| Джерело | Що дає | Доступ | Статус / пріоритет |
|---|---|---|---|
| **Photon** ✅ | автодоповнення адрес з номерами будинків, найближчі об'єкти (зупинка, магазин, аптека, школа, садок, медицина, парк) | безкоштовно, fair use; **публічний інстанс тротлить сплески** — self-host (щотижневі дампи GraphHopper) | підключено |
| **Geoapify** ✅ (опційно, ключ) | те саме з SLA (free tier), дані OSM, показ на будь-якій карті | ключ | підключено як провайдер №1 |
| **Overpass (OSM)** ✅ | щільність інфраструктури, магістралі/колії (шум) | безкоштовно; нестабільний під навантаженням → self-host | підключено |
| **Google Maps Platform** | найкраща якість POI/автодоповнення в Україні | платно; **ToS: дані Places можна показувати лише на Google-карті** | ❌ не обрано зараз: ламає OSM/MapLibre-стек і ціноутворення. Шлях міграції описано нижче |
| **Visicom** | український геокодер з адресною базою | комерційний API | P2 альтернатива для адрес |
| **SaveEcoBot** | якість повітря / радіаційний фон за станціями поруч | API (ключ за запитом), CC BY 4.0, обов'язкова атрибуція | **P1** — простий і цінний сигнал |
| **Укриття** (OSM `amenity=shelter` + міські карти укриттів) | відстань до укриття — критично під час війни | OSM + муніципальні дані | **P1** |
| **Графіки відключень** (Львівобленерго, Прикарпаттяобленерго, Закарпаттяобленерго) | ризик блекаутів / черга відключень будинку | неофіційні JSON сайтів обленерго | P2 (обережно з ToS) |
| **Пам'ятки архітектури** (реєстр Мінкульту, OSM `heritage=*`) | обмеження на ремонт/перепланування історичних будинків (Львів!) | open data / OSM | **P1** для Львова |
| **Генплани, ДПТ** (геопортали міст) | майбутня забудова, дороги | веб-ГІС; машинний доступ — to-verify (портал відкритих даних Львова з цього середовища недоступний, ймовірно гео-блок) | P2 |
| **GTFS транспорту** | реальний час у дорозі громадським транспортом | to-verify | P2 |

## 4. Рекомендований план інтеграцій

1. **Зараз (P0)**: DIM.RIA ✅, НБУ ✅, Photon/Geoapify ✅, Overpass ✅ (self-host у production), операторський процес для ДРРП (PDF → AI-витяг → юрист).
2. **Наступний спринт (P1)**: Opendatabot API (юр-автоматизація + моніторинг), ЄДЕССБ API (новобудови), Єдиний реєстр боржників + ЄДР (open data), SaveEcoBot (повітря), укриття, пам'ятки.
3. **Партнерства**: ЛУН (новобудови, історія цін), агентства — для бази *фактичних* угод.
4. **Потім (P2)**: Prozorro.Sale (калібрування знижки торгу), YouControl, курортна аналітика, графіки відключень, GTFS.

### Чому не Google Maps зараз
Якщо в майбутньому знадобиться Google Places (кращий POI-покрив), міняти треба **разом із картою**: умови Google вимагають показувати дані Places на Google-карті. Архітектура це дозволяє: провайдери геоданих ізольовані в `src/server/sources/geo.ts`, карта — в `src/components/map/map-view.tsx`.
