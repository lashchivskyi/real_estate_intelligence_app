# Data Sources — Ukraine / Lviv first

Принципи: **official → open data → licensed API → партнерство → (останнім) ручний збір.** Скрапінг порталів — ні:
порушує ToS, нестабільний, юридично ризикований. Кожне джерело в коді — це `DataSourceDescriptor` (`src/domain/provenance`) з полями
`license`, `access`, `rateLimit`, `legalNote`, `status`.

Статус: **verified** = підтверджено при дослідженні; **to-verify** = відомо з практики, потребує перевірки договору/умов перед інтеграцією.

> ⚠️ Дослідження виконано 2026-10-23. Умови доступу до реєстрів в Україні змінюються (воєнний стан, реформа ДРРП, Дія). Перед кожною інтеграцією — перевірити актуальний порядок доступу та ToS.

## 0. Що підключено в коді (v0.2) — живі дані замість хардкоду

Кожен звіт збирає дані в `src/server/live-report.ts`; кожне джерело повертає статус (`live / fallback / demo / not-configured / error`), який показується у розділі «Джерела й методологія» з часом отримання.

| Сутність | Джерело (живе) | Код | Кеш | Fallback |
|---|---|---|---|---|
| Координати адреси, район | **Nominatim** (OSM), bounded-viewbox по місту | `server/sources/nominatim.ts` | 30 днів | центр району → центр міста |
| Інфраструктура: транспорт, школи/садки, магазини, парки, паркінг, офіси, медицина, нічне життя | **Overpass API** (OSM), один запит на точку | `server/sources/overpass.ts` → `domain/location/intel.ts` | 7 днів (точка округлена до ~100 м) | профіль району з конфігу (позначений «некалібровано»), або «немає даних» |
| Шум (проксі) | Відстань до магістралей/залізниці/трамваю (OSM, `out geom`) | `intel.ts → distanceToLine` | — | — |
| Час до центру | Оцінка: відстань × 1.3 / типова швидкість (ESTIMATE) | `travelEstimate` | — | — |
| Порівнянні об'єкти (продаж) | **DIM.RIA API** `/dom/search` → `/dom/info/{id}` (≤24 оголошення) | `server/sources/ria.ts` | пошук 6 год, оголошення 24 год | синтетичні demo-comps від датованого бенчмарку |
| Оренда | **DIM.RIA API**, `operation_type=3`, медіана $/м² | `ria.ts` | 6/24 год | міський орієнтир з джерелом |
| Id регіонів/міст DIM.RIA | `/dom/states`, `/dom/cities/:state` — **резолвяться за назвою**, не хардкодяться | `resolveRiaIds` | 30 днів | — |
| Курс UAH/USD | **НБУ** `statdirectory/exchange` (офіційно, без ключа) | `server/sources/nbu.ts` | 6 год | ціни лише в USD |

Індикатори OSM (метод `osm-poi-indicators 1.0.0`): кількість об'єктів у радіусі (зупинки 500 м, школи 1 км, магазини 600 м, паркінг 400 м …) → `100·(1−e^(−n/k))`; тиша = 100 − штрафи за близькість магістралі/колії/барів. Сирі лічильники й відстані — FACT, бали — INFERENCE. Покрито unit-тестами.

### Обмеження публічних інстансів (виявлено при тестуванні 2026-10-24)
Публічний Overpass періодично відповідає 502/timeout під навантаженням. Код пробує кілька endpoint-ів (`OVERPASS_URLS`) з коротким таймаутом і деградує до fallback, не ламаючи звіт. **Для production — власний інстанс Overpass + Nominatim** (Docker, дамп Geofabrik `ukraine-latest.osm.pbf`) або платний провайдер (Geoapify/MapTiler) за тим самим інтерфейсом.

## F. Курси і макро

НБУ open API (курс UAH/USD/EUR; офіційний, безкоштовний — **verified** як публічний сервіс), ставки по кредитах НБУ, дохідність ОВДП (для investment discount rate).

## G. Правила використання даних (compliance)

1. **ToS first.** Для кожного джерела в `DataSourceDescriptor.legalNote` — висновок: `allowed | allowed-with-attribution | license-required | forbidden`.
2. **Привласнені дані (non-open)** не зберігаємо довше, ніж дозволяє ліцензія; зберігаємо похідні (агрегати).
3. **Персональні дані** (власники в ДРРП) — мінімізація, access control, audit log, відображення лише клієнту, який замовив перевірку.
4. **Rate limits** — черга з backoff лише коли з'явиться реальна потреба (не додаємо Redis/queues заздалегідь).
5. **Атрибуція** — окремий блок «Sources & methodology» у кожному звіті.

## H. Прогалини, які ми показуємо чесно

- Реальні ціни угод — недоступні публично → оцінка базується на оголошеннях + корекція `askToSold` discount (параметр, калібрується на кейсах).
- Історія оголошень (days on market) — потребує партнерства з LUN/RIA або власного моніторингу.
- Шум/екологія/ризики затоплення — немає надійних даних → показуємо «дані відсутні».
